    プライバシーポリシー

    このポリシーは、Daiki Tsukuda が提供する「かんたんパスワード生成」に適用されます。

    パスワードと設定#

    パスワードは端末上で生成し、アプリから外部に送信しません。生成したパスワードは、アプリのメモリに一時的に保持します。コピーすると、パスワードは端末のクリップボードに入ります。

    文字数や文字の種類などの設定は端末に保存します。

    広告#

    広告の配信と効果測定、不正防止のために Google AdMob を利用します。Google は広告識別子、IP アドレスとそこから推定されるおおよその地域、アプリや広告の操作情報、診断情報などを取り扱う場合があります。

    広告識別子の利用は、端末のプライバシー設定で管理できます。

    Google の広告に関するポリシー

    アプリ内購入#

    広告削除の決済は、アプリを入手したストアが処理します。購入の確認と復元には RevenueCat を利用します。RevenueCat は自動で発行するアプリユーザー ID と購入情報を取り扱います。

    お問い合わせとデータの削除#

    フォームに入力された情報は、お問い合わせへの回答と対応に利用します。フォームの回答には一律の保存期間を設けていません。

    プライバシーに関するお問い合わせやデータの削除依頼は、以下のフォームで受け付けます。依頼内容を確認し、適用される法令に従って対応します。
