    プライバシーポリシー

    Daiki Tsukuda（以下、「当方」といいます）が提供するアプリ「今日の歩数」（以下、「本アプリ」といいます）のプライバシーポリシーを以下に定めます。

    ヘルスケア情報の利用について#

    本アプリは、利用者の許可を得たうえで、Appleのヘルスケア（HealthKit）から今日の歩数を読み取り、アプリおよびウィジェットに表示します。ヘルスケアへのデータの書き込みは行いません。

    情報の保存について#

    取得した歩数と取得日時などを、ウィジェットでの表示のため、端末内のアプリとウィジェットの共有領域に保存します。保存内容は更新時に上書きし、過去の歩数履歴として蓄積しません。また、ヘルスケアへのアクセスを要求した状態を端末内に保存します。

    ロック中も、最後に取得した当日の歩数と取得時刻をウィジェットに表示します。

    選択したウィジェットのデザインや表示設定、確認済みのプレミアム機能の利用状態も、端末内に保存します。

    外部送信・第三者提供について#

    本アプリには広告配信の機能はありません。読み取った歩数を当方のサーバー、RevenueCatその他の第三者へ送信することはありません。歩数を広告やマーケティングのために利用することもありません。

    アプリ内課金について#

    本アプリは、アプリ内課金の管理にRevenueCat, Inc.が提供するRevenueCatを利用します。購入の確認・復元、プレミアム機能の利用可否の判定、不正利用の防止、および購入状況・売上の分析のため、以下の情報をRevenueCatへ送信します。

    • RevenueCatが自動生成する匿名ユーザーID
    • 購入した商品、購入日時、取引ID、購入金額・通貨、購入・返金の状態などの購入情報
    • OSや端末の種類、アプリのバージョンなどの技術情報、および最終利用日時

    本アプリにはアカウント登録機能はなく、氏名やメールアドレスを匿名ユーザーIDに紐づけてRevenueCatへ送信しません。広告目的の他社アプリ・ウェブサイトを横断するトラッキングには利用しません。

    決済はAppleが処理します。当方およびRevenueCatが、本アプリを通じてクレジットカード番号などの支払い情報を取得することはありません。

    RevenueCatによる情報の取り扱いについては、RevenueCatのプライバシーポリシーをご確認ください。

    読み取り許可の取り消し・データの削除について#

    歩数の読み取り許可は、端末の設定またはヘルスケアアプリからいつでも変更できます。許可を取り消しても、取得済みの端末内データが直ちに削除されるわけではありません。

    本アプリを端末から削除しても、ヘルスケアに記録されている元の歩数データや、Apple・RevenueCatで管理する購入履歴は削除されません。RevenueCatで管理する情報の削除については、以下のお問い合わせフォームからご連絡ください。購入記録など、法令への対応や購入の確認・復元に必要な情報は、必要な期間保持される場合があります。
